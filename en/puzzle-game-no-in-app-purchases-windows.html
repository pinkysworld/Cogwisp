Logic puzzles for Windows with no in-app purchases

Many puzzle games start free and later sell hints, lives or levels. If you would rather pay once and play everything, these points help you search.

Business models at a glance

There are roughly three: free with ads, free with in-app purchases or subscription, and a one-time purchase. With a one-time purchase you decide up front whether the game is worth the price, and nothing is added later.

The Microsoft Store product page states whether a game has in-app purchases. Read that before installing.

What a fair puzzle game looks like

All levels should be reachable without extra purchases, hints should not cost coins, and there should be no waiting timers. The description and screenshots should also state the scope clearly, for example the number of levels.

Cogwisp on Windows

Cogwisp is a routing puzzle: you connect gears and belts so mechanical power reaches every target, paying attention to direction and speed. The Windows version in the Microsoft Store is a one-time purchase: all 36 rooms are unlocked right away, with no in-app purchases, no subscription and no ads. The current price is shown in the Store.

A different split is planned for Android (prologue rooms free, further rooms via a one-time in-app purchase). This page is about the Windows version.
